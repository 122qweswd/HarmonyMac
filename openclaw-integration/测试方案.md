以下配置是经过多轮调试后的**最终定稿**，修改模型相关配置时以此为基准。

### 2.1 运行时配置模板

文件：`NodeRuntimeHost/config/openclaw.template.json`

```json
{
  "gateway": { "mode": "local", "port": 18800, "auth": { "mode": "none" } },
  "agents": {
    "defaults": {
      "model": { "primary": "aajax/gpt-5.6-luna" }
    }
  },
  "models": {
    "mode": "merge",
    "providers": {
      "aajax": {
        "baseUrl": "https://api.aip.aajax.top:20443/v1",
        "apiKey": "${ANTHROPIC_AUTH_TOKEN}",
        "api": "openai-completions",
        "models": [
          {
            "id": "gpt-5.6-luna",
            "name": "GPT 5.6 Luna",
            "reasoning": false,
            "input": ["text"],
            "contextWindow": 200000,
            "maxTokens": 8192
          }
        ]
      }
    }
  },
  "plugins": {
    "entries": {
      "a2a-gateway": {
        "enabled": true,
        "config": {
          "server": { "host": "127.0.0.1", "port": 18810 },
          "agentCard": {
            "name": "MutualInfectionMac",
            "description": "harmonymac A2A node",
            "skills": [
              { "id": "chat", "name": "chat", "description": "chat bridge" }
            ]
          },
          "security": { "inboundAuth": "none" }
        }
      }
    }
  }
}
```

### 2.2 配置版本

文件：`MutualInfectionMac/Application/NodeRuntimeManager.swift`

```swift
private static let configTemplateVersion = 11
```

> 改模板内容时必须把这个版本号 +1，App 启动才会重新生成沙盒配置。

### 2.3 Xcode Scheme 环境变量

`Product → Scheme → Edit Scheme → Run → Arguments → Environment Variables`：

| 变量 | 值 | 说明 |
|------|----|----|
| `ANTHROPIC_AUTH_TOKEN` | 你的真实 Token | 代理认证；`${ANTHROPIC_AUTH_TOKEN}` 在模板里被解析 |
| `ANTHROPIC_API_KEY` | 同上（可选） | 兼容兜底 |

> 不要设置 `ANTHROPIC_MODEL`：它会覆盖模板里的模型名，曾导致模型被误识别为 `openai/...` 或 `anthropic/...` 而报 `Unknown model`。

### 2.4 为什么用 `openai-completions` 而非 `anthropic-messages`

经实测（`probe_aajax.sh`），代理 `api.aip.aajax.top`：

- Anthropic **流式** SSE 不规范（连续 `message_start` 无 `message_stop`）→ OpenClaw 依赖的 `pi-ai` 库**硬编码** `stream:true` 无法关闭 → 报 `Unexpected event order`；
- OpenAI 流式 / 非流式 / Anthropic 非流式均正常。

由于 OpenClaw 无法禁用流式，必须走 OpenAI 路径，故 `api: "openai-completions"`。

## 十一、T5 退出清理（进程组）

> 本项是本次集成中**修复后才通过**的核心改动：原先仅 `process.terminate()` 杀父进程，`openclaw-gateway` 变孤儿继续占用端口。修复后用 `setpgid` 建独立进程组 + `kill(-pgid)` 整组终止。

### 11.1 记录运行时 PID

```bash
pgrep -af 'openclaw.mjs gateway|openclaw-gateway|NodeRuntime/node/bin/node'
```

### 11.2 正常退出 App（App 侧）

**必须用正常退出**：`⌘Q` 或菜单「鸿蒙星河互联 → 退出」。**不要**点 Xcode Stop（它直接杀 App，不触发 `applicationWillTerminate`，无法验证清理逻辑）。等待 3 秒。

### 11.3 检查清理结果（终端侧）

```bash
pgrep -af 'openclaw.mjs gateway|openclaw-gateway|NodeRuntime/node/bin/node' || echo "runtime processes cleaned"
for p in 18800 18810 18811; do lsof -nP -iTCP:$p -sTCP:LISTEN || true; done
```

### 期望

- 无 `openclaw` / `openclaw-gateway` 残留；
- 18800/18810/18811 全部释放；
- 不需要手动 `pkill`。

### 故障处理

若仍有残留（多发生在 Xcode Stop 后），手动清理：

```bash
pgrep -f 'openclaw.mjs gateway|openclaw-gateway' | xargs -r kill -TERM
sleep 3
pgrep -f 'openclaw.mjs gateway|openclaw-gateway' | xargs -r kill -KILL
```

### 作用

验证 `applicationWillTerminate → NodeRuntimeManager.stop()` 的进程组清理有效，无孤儿进程与端口泄漏。

## 十四、T8 待完成：Sandbox 任意文件访问

### 现状


实测：让 Agent 读 `/tmp/openclaw-probe.txt`，返回「无法读取该文件：权限不足」。这是 macOS Sandbox 的预期行为，**不是 OpenClaw 集成缺陷**。

### 待完成的方案

OpenClaw 文件读取能力本身已具备，只需 App 层把「经 sandbox 授权的文件路径」交给它：

1. **NSOpenPanel**（推荐）：用户在 App 内选文件 → App 拿到 security-scoped URL → 路径传给 OpenClaw Agent；
2. **Entitlement**：在 `*.entitlements` 加 `com.apple.security.files.user-selected.read-only`；
3. **Security-scoped bookmark**：对常用目录持久化访问授权。

### 验证目标（实现后）

- 用户通过 NSOpenPanel 选一个 Mac 任意位置文件；
- App 把该 URL 路径通过 A2A `message/send` 传给 OpenClaw；
- Agent 读取并返回文件内容（如唯一标记字符串）。

## 十六、已知问题与限制

1. **`openclaw-bundle-output/` 约 1.2G**：全量产物，未裁剪；阶段 5 优化项。
2. **代理 Anthropic 流式 SSE 不规范**：故 `api` 必须用 `openai-completions`，不能用 `anthropic-messages`。
3. **`pi-ai` 硬编码 `stream:true`**：无法通过配置禁用流式（anthropic provider 第 151 行）。
4. **`ANTHROPIC_MODEL` 会覆盖模型名**：Scheme 里不要设这个变量。
5. **Xcode Stop 不触发退出清理**：验证 T5 必须用 `⌘Q` 正常退出。
6. **Sandbox 阻止任意文件访问**：见 T8，属 App 授权待办。
7. **`runtime.log` 不记录停止日志**：`ShareAPI.shared().log` 未必写入文件，非阻断。
8. **`openclaw-source/` 未入 git**：新协作者需另行获取。
9. **`project.pbxproj` 的 Build Phase input/output paths** 仍引用旧路径，增量构建可能不重跑 Phase，建议清理。
